# Nexentis website

Static GitHub Pages website for nexentis.co.in.

Files:
- index.html
- style.css
- script.js
- images/

## Deploy
1. Create a public GitHub repository.
2. Upload all files/folders.
3. Settings -> Pages -> Deploy from branch -> main -> /root.
4. Add nexentis.co.in under Custom domain.
5. In GoDaddy DNS, add the GitHub Pages records shown by GitHub.
